# MeetingRec releases

> **Alpha.** Every build here is an alpha (pre-release). There is no beta or official release yet; versions and behaviour can still change.

Release builds (dmg) of MeetingRec, a macOS menu-bar app that records meetings and transcribes them locally with mlx-whisper.

Open the dmg from the latest release and drag MeetingRec into Applications. Installed copies check this repository for updates and update themselves.
